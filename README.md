# RPL WEB LAUNDRY

## Deskripsi
Aplikasi berbasis web untuk manajemen laundry yang memungkinkan admin mengelola pelanggan dan transaksi laundry.

## Fitur
- Login Admin
- CRUD Data Pelanggan
- Input Transaksi Laundry
- Status Laundry
- Perhitungan Harga

## Teknologi
- HTML
- CSS
- PHP Native
- MySQL

## Cara Menjalankan
1. Import database di folder /database
2. Jalankan di localhost (XAMPP)
3. Akses melalui browser
